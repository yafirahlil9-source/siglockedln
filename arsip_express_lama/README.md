# Arsip Template Express Lama

Folder ini merupakan arsip template/boilerplate Express lama dan **tidak digunakan** oleh aplikasi utama.

Aplikasi utama Siglockedin/EduSmart berjalan langsung dari root direktori proyek melalui file:
* `server.js` (Backend API, Database MySQL, Biometrik Wajah, Geofencing GPS)
* `public/` (Frontend Antarmuka Web, Dashboard, Kamera Biometrik, Jam Live)
